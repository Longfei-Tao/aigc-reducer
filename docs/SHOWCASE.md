原 README 主要是完整的 CLI 手册。核心问题不在缺少徽章，而在信息顺序：一眼难以看出交什么文件、怎么开始、自己的工具怎么装、能获得什么改写。

本次把首页改为“用途 → 改写图 → 快速开始 → 工具入口 → 示例与边界”；六个子命令的说明移到 CLI 文档。增加跨客户端安装指南、英文入口和三组合成改写示例。图片中的字数、标点和引用来自公开示例数据；没有给出虚构的检测分数。

安装入口依据各厂商官方文档，来源就近列在 [INSTALL.md](INSTALL.md)。文档级兼容与客户端实测分开表达；目前仍需维护者逐客户端完成“发现技能 → 执行 Python → 打开最终 Word”的验收后，才能标注实测版本。

后续有真实、获授权、可脱敏的同平台检测前后报告，再补充效果案例，并记录日期、模型、范围、平台口径和异常。没有这些证据前保留改写示意，不用“100% 过检”等宣传代替验证。
