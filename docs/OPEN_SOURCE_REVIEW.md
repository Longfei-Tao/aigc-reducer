## 生成内容、学术使用与宣传

可以介绍“中文论文表达编辑、对齐回写、规则检查”，不应承诺“百分百过检、保证原创、无法识别、所有样式不变”。检测疑似度不证明作者身份，MIT 免责条款也不能免除依法承担的责任。使用者仍需遵守学校、期刊和检测平台规定；降低分数不能替代如实披露 AI 辅助。

《人工智能生成合成内容标识办法》自 2025-09-01 施行，对相关服务和传播行为规定标识要求，并禁止恶意删除、篡改、伪造、隐匿规定标识及提供相应工具服务。正常编辑文字与去除法定标识应严格区分，本项目不提供后者。适用范围需结合实际提供与传播方式判断，不能把任何本地私人编辑都直接等同于公众服务。[广电总局法规全文](https://www.nrta.gov.cn/art/2025/3/14/art_113_70340.html?xxgkhide=1)

## 本地工具与公开服务

分发本地脚本、使用第三方模型、经营公开云服务的责任不同。《生成式人工智能服务管理暂行办法》第二条以向境内公众提供相关服务为适用范围，未向公众提供服务的部分研发应用活动不适用该办法；未来改为 SaaS/API 时需重新评估提供者身份、内容管理、安全评估/备案等适用要求，不能沿用本地工具的结论。[工信部全文](https://wap.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2023/art_4248f433b62143d8a0222a7db8873822.html)

Python 脚本不主动联网不等于宿主模型离线。论文可能包含个人、医疗、商业秘密或未公开研究数据。发送云端前应确认处理权限、宿主留存政策和机构规定；涉及个人信息与跨境提供时应按实际情形核对合法性基础和适用要求，不能只靠 README 声明免责。[工信部《个人信息保护法》](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_515a4b20c12f430eab54bb4f56d89f56.html)
