# 改写指令（唯一来源）

以下是维护者沿用的五条风格指令，不代表已完成检测效果或跨模型对照验证。**保持五条原文，不得改写、概括、精简或补充条目。** 事实保护及执行约束优先于风格要求。

调用方式：取本文件第一条分隔线 `---` 之后的全部内容（含末尾「修改段落:」），
在「修改段落:」之后直接拼接待改段落原文。`batch --prompt` 会在风格指令之前另加不检索、事实保护和回复格式约束；这些文字不能替代客户端的搜索开关或推理设置。

指令:1. 在不大幅改动原文总字数的情况下，只调整语序、替换同义词、变换主谓宾结构，补充那些无主语句的主语，语言简化，让语句有逻辑且通顺，贴合基础论文写作规范。
2. 弱化专业感，要营造作者写起来很吃力、勉强写完了的普通文笔效果，删除"我觉得、我认为"这些主观表述，整体文笔平实普通。
3. 弱化语句精炼度，贴合新手写作状态。
4. 减少句号使用，多用逗号、分号衔接；将长句拆分成短句，高频词换同义词，专业词汇替换为通俗简单表达。
5. 打乱句子原有结构，灵活互换，把字句、被动句，调整语句语序，不改变原文核心表意。删除过于口水话的口语化表达，保持基本语言逻辑,严格执行
